# Microservices with .NET

Repositório criado durante meus estudos de **Microserviços com .NET**, com o objetivo de aprofundar meus conhecimentos em desenvolvimento backend, arquitetura de aplicações e comunicação entre serviços.

O projeto consiste no desenvolvimento de uma aplicação de **e-commerce** dividida em diferentes microserviços, explorando diferentes formas de comunicação, persistência de dados e organização da aplicação.

## 🧩 O que estou estudando neste projeto

* Desenvolvimento de **Microserviços com .NET 8 e C#**
* **ASP.NET Core Web API** e Minimal APIs
* Comunicação síncrona entre serviços utilizando **gRPC**
* Comunicação assíncrona e orientada a eventos utilizando **RabbitMQ** e **MassTransit**
* **API Gateway** com YARP
* **CQRS** e **MediatR**
* **Clean Architecture**, **DDD** e Vertical Slice Architecture
* **Entity Framework Core** e Dapper
* Bancos relacionais e NoSQL
* **PostgreSQL, SQL Server, SQLite e Redis**
* **Docker** e Docker Compose para containerização
* Design Patterns e princípios **SOLID**
* Tratamento de exceções, validações, logging e Health Checks

## 🛒 Sobre o projeto

A aplicação simula uma plataforma de e-commerce composta por diferentes serviços:

* **Catalog** — gerenciamento de produtos
* **Basket** — gerenciamento do carrinho
* **Discount** — cálculo de descontos
* **Ordering** — processamento dos pedidos
* **YARP API Gateway** — ponto de entrada para comunicação com os serviços

Os microserviços utilizam diferentes estratégias de comunicação e persistência, permitindo praticar conceitos de **arquitetura distribuída, integração entre serviços e consistência de dados**.

## 🏗️ Arquitetura

Durante o desenvolvimento, são explorados diferentes padrões e abordagens de arquitetura, como:

* CQRS
* Domain-Driven Design (DDD)
* Clean Architecture
* Vertical Slice Architecture
* Comunicação síncrona com gRPC
* Comunicação assíncrona baseada em eventos
* API Gateway
* Design Patterns
* Princípios SOLID

## 🐳 Containerização

Os microserviços e seus recursos de infraestrutura são executados utilizando **Docker e Docker Compose**, incluindo bancos de dados, cache distribuído e message broker.
